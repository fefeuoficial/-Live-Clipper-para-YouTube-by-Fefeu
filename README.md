## Como instalar

1. Vá até a página de https://github.com/fefeuoficial/-Live-Clipper-para-YouTube-by-Fefeu/blob/main/Live%20Clipper%20para%20YouTube%20by%20Fefeu.zip deste repositório e baixe o arquivo **source code (zip)** ou o arquivo `.zip` da versão mais recente.
2. Extraia o conteúdo do arquivo `.zip` em uma pasta no seu computador.
3. Abra o Google Chrome e acesse: `chrome://extensions/`
4. No canto superior direito, ative o **Modo do desenvolvedor** (Developer mode).
5. No canto superior esquerdo, clique no botão **Carregar sem compactação** (Load unpacked).
6. Selecione a pasta onde você extraiu os arquivos da extensão.
